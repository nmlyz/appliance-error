appliance-error is a small program that writes one honest appliance error message as a single line: a microwave reports that its turntable has stopped turning, and states what that means for the soup inside it.

## The line

The message is built in two beats: the fault the machine reports, then what the fault means for the food. The turntable motor has failed, so the soup heats on one side only — on the far side the heat is only a rumor. The humor comes out of the truth of the fault, in the machine's own flat voice.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run.
